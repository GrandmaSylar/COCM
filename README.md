
  # Church Management System MVP

  
  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
  
  ## Deployment
  
  This project is configured to be deployed on **Render**.

  ### Render Deployment Steps:
  1. Create a [Render](https://render.com/) account.
  2. Click **New** -> **Web Service**.
  3. Connect your GitHub repository.
  4. Render will automatically detect the `render.yaml` configuration in the root directory.
  5. Add your environment variables in the Render Dashboard (from `.env.example`).
  6. Click **Create Web Service**. Render will automatically build and deploy the app.
